# 岗位 JD（虚构演示模板）

> 本文是虚构岗位，仅用于演示。正式使用前请替换为本次应聘岗位的 JD；岗位要求不代表候选人已有的经历或技能。

## 岗位信息

- 岗位名称：Python 应用开发工程师（演示岗位）
- 岗位级别：初级
- 业务背景：开发内部 Web 工具，并探索文档问答等 AI 应用功能

## 工作职责

- 使用 Python 编写和维护 Web API，与前端配合完成业务功能。
- 设计基础数据模型，编写 SQL，处理输入校验、异常与日志。
- 编写单元测试，参与代码评审，定位常见接口与数据问题。
- 在有明确需求时接入大模型 API，验证文档问答的结果与边界。

## 任职要求

- 理解 Python 常用数据结构、函数、面向对象与异常处理。
- 熟悉至少一种 Python Web 框架，了解 HTTP、REST API 和基础网络知识。
- 掌握 SQL 基础，能解释索引、事务及常见查询优化思路。
- 能使用 Git，并说明自己参与项目的职责、实现过程和取舍。
- 对技术结论和项目事实表达准确，能区分已验证结果与待验证方案。

## 加分项

- 了解 JavaScript 与简单前端交互。
- 了解大模型 API、上下文管理、文档检索和回答质量评估。
- 了解自动化测试、部署及基础可观测性。

## 本次面试关注点

Python 基础、HTTP 与数据库基础、项目实现和个人职责；根据候选人的实际经历逐步追问，不假设候选人满足所有加分项。
